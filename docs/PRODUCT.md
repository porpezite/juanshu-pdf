# 卷舒 PDF 产品说明

卷舒，取自「卷舒开合」：把纸页卷起来扫描，再舒展开来编辑。英文拼音品牌名是 Juanshu PDF。包名保持 `com.juanshu.pdf`。

这份文档定优先级、会员边界和多端顺序。实现进度以 [STATUS.md](STATUS.md) 为准，模块怎么拆以 [ARCHITECTURE.md](ARCHITECTURE.md) 为准。会员和分布式在这里先写成规则，当前版本还没有购买和接力。

## 竞品里要拿走的，和不要学的

对照的是国内用户最熟的两款：夸克扫描王，以及扫描全能王（合合信息）。两者都证明了一件事：用户要的是一条能走完的链路，不是散落的工具。拍下来，裁正，增强，收成多页 PDF，认字，再合并、拆分、签名。这条链路做不完整，后面的差异点没有意义。

### 夸克扫描王

- 手机上的扫描闭环完整：自动找边、滤镜、多页、证件、去手写、转 Word、翻译。
- 和夸克账号、网盘绑在一起。批量、高清和部分导出经常导向登录或会员。
- 主场是手机。鸿蒙平板、折叠屏和 PC 不是它的布局中心。
- 免费结果有时被清晰度或水印卡住，文件和账号绑得紧。

### 扫描全能王

- 品类最全：扫描、OCR、PDF、签名、证件、书籍、白板、表格。
- 手机、桌面和 Web 都有，云同步是它留下来的理由。多端这件事值得学，顺序不能照搬。
- 收入靠会员。免费导出常见水印、次数限制和功能锁。
- 用户长期不满的是自动续费、价格跳变，以及纸页上传到别人的云。

### 对卷舒的结论

P0 先把两者共有的闭环做扎实：扫描、编辑、识别、整理。这四块已经是四个页面，不合并成一个大页。

不学三件事：导出结果加水印、默认自动续费、不登录就不能在本机扫描。

差异不靠把功能清单做更长，靠下面五件事：原档优先、鸿蒙分布式、本地优先、诚信会员、场景包。

## 会员

档位名称用 Free、Plus、Pro。另有一次性加油包，不并进订阅。价格在实际上架前单独公布，本文不锁数字。

### Free

本机扫描、裁边、滤镜、多页 PDF、基础编辑、本机 OCR、合并拆分旋转和搜索重命名。导出的文件不加水印，不要求登录。页数满足个人日常，不把「能读自己的文件」放进付费墙。

### Plus

更高的单次页数、场景包（证件、票据、合同）、以及用户自己的华为账号下的设备间接力。没有广告。到期后，已经生成的文件仍可打开、导出和编辑。

### Pro

面向用量大的个人：批量处理、密码 PDF、自定义图章、更完整的 OCR 块结果。仍然不锁已经落盘的文件。

### 一次性加油包

按次或按页购买，用完即止。例如高清导出包，或单独买一个场景包。加油包不转成订阅，不默认续费，不要求先开通 Plus。

### 诚信规则

1. 已经生成或导入的文件属于用户。会员到期不锁文件，不补打水印，不降低已有文件的清晰度。
2. Free 的导出结果不加水印。
3. 订阅不默认勾选自动续费。续费前通知。应用内可以取消，取消路径和购买路径一样能找到。
4. 加油包是一次买卖，不会在用完后变成按月扣款。
5. 本机的拍摄、阅读和基础整理不强制登录。
6. 购买前展示完整价格和周期，不另加未声明的费用。
7. 不用虚假倒计时、预勾选或藏在角落的同意框催促订阅。

## 五个差异点

### 原档优先

扫描件先保证纸页还能对上，而不是先做成一张过锐的「扫描王风格」图。卷舒自己的 PDF 保留页面、正文和批注；外部 PDF 交给系统 PDF Kit，不在可移植核心里猜结构。增强滤镜是可选项，默认保留原图这一档。

### 鸿蒙分布式

手机适合拍，平板和 PC 适合改。同一套页面按窗口宽度切换，不维护两套界面。下一步才是真正的跨设备接力：手机上的未完成扫描，到平板或 2in1 上继续。分布式用系统能力，不自建一套必须上传的网盘。

### 本地优先

文件先写在本机沙箱。OCR、找边和滤镜能在本机完成的，不先上传。云只作为用户明确打开的接力或备份，不作为打开应用的条件。

### 诚信会员

收费的是增量：更高额度、场景包、批量和密码文档。不收费的是「我的文件还在，而且没有水印」。规则见上一节，实现晚于规则，避免先上支付再补条款。

### 场景包

证件、票据、合同这类纸页，裁切比例、命名和导出不同，但不该拆成另一个 App。场景包是可选层，可以单买。P0 的通用扫描不依赖任何一个场景包。

## 多端顺序

一套核心，多套壳。壳的顺序如下，前一段能在真机上用，再开下一段。

1. **HarmonyOS 手机。** 当前主场。扫描、编辑、转换识别、文档四个模块，DevEco 签名后装到手机。
2. **HarmonyOS 平板、折叠屏和 PC（2in1）。** 仍是这一份 ArkUI。窗口宽度按 `320vp`、`600vp`、`840vp` 分成 sm、md、lg。xs 和 sm 用手机首页：工具宫格、最近文件、底部四个入口。md、lg 以及更宽用左侧栏加右侧最近文件。折叠屏内屏变宽时走宽屏，外屏仍走手机。扫描页不拆两套，预览、裁边和快门始终叠在一个 Stack 里。
3. **Android 和 iOS。** 重做界面和四个端口（文件、PDF、OCR、相机）。核心算法和测试不改。
4. **Windows、macOS、Linux。** 桌面壳，端口改用桌面的 PDF 和文件 API。
5. **Web。** 最后做。浏览器里没有鸿蒙套件，PDF 和相机都要换实现，产品规则不变。

技术上的端口和「不要用一套 UI 框架吃掉鸿蒙套件」写在 [ARCHITECTURE.md](ARCHITECTURE.md)。
